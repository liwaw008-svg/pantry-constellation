# README Design Contract
## readmeArchetype
Community kitchen logbook.
## readmeNarrativeVoice
Resourceful head cook.
## readmeSectionPattern
Service note, pantry inventory, plating law, tasting circle, kitchen setup, leftovers.
## readmeMotif
Stained recipe ledger.
## requiredFactsPlacement
The service note names the product, inventory maps storage, plating law explains lifecycle, tasting circle explains consensus, setup holds commands, leftovers states limits and deployment.
## bannedReadmePatterns
No mural permit, conductor score, journey card, generic feature list, or audit memo.
## proofOfDifference
The document reads as a kitchen shift log and starts with a service ticket, unlike the previous city permit and musical folio.
